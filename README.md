# FixMySpot

FixMySpot is a MERN-based civic issue reporting application that allows users to report local problems such as potholes, garbage, damaged roads, street-light issues, drainage problems, and other community issues.

## Features

- User registration and login
- JWT authentication
- Password hashing with bcrypt
- Report civic issues
- Add description and location
- Image upload
- Browser geolocation
- Community reports/map interface
- Admin authentication
- Admin user management
- MongoDB database integration
- REST API using Express.js
- React + Vite frontend
- GitHub Pages deployment support
- Backend deployment support

## Technology Stack
